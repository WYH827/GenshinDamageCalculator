# 提瓦特 · 伤害工作台

原神四人队伍伤害工作台。已接入常规元素/物理直伤与五种月曜/星烁直伤，点击“开始计算”后逐时间轴事件计算暴击期望、总伤害及DPS，并展示面板、效果来源和公式代入过程。支持逐事件手动指定蒸发/融化；不模拟元素附着、激化、剧变及多人反应伤害。

计算模块的公式说明与设计见 [伤害计算实装计划](docs/伤害计算实装计划.md)，已核对 Alioth 12 个子界面和 27 个公式；[来源核对记录](docs/alioth-formulae-audit.json)保留逐页公式数量及校验摘要。原先的“无效果0秒面板”现明确称为“角色局外数值”；“角色基础数值”只含角色自身与武器基础攻击力。

## 启动

安装 Node.js 22.12+ 或 24+，在项目目录执行：

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173/。Windows 也可以双击 `启动工作台.cmd`，自动检查依赖并打开浏览器。关闭终端会停止服务。

## 已实现

- **角色**：固定 4 位，可调整顺序。名称、单字简写、命座、金数、限定金数、1～90/95/100级（自动对应0/1/3命星）、七种角色元素、基础三维与突破属性。基础暴击率5%、暴击伤害50%只读；突破选择属性后填增量，涵盖百分比三维、充能、暴击、暴伤、精通、治疗、物理和七元素伤害。支持预设库和 JSON 预设导入导出。
- **武器**：与角色页一致的四卡片切换布局，每次显示一位角色的装备。固定 4 把，名称、用于队伍命名的简写、金数、限定金数、基础攻击力、最多 1 条副词条（含七种元素伤害、物理伤害加成及 NOT IMPORTANT）、多个效果；支持预设。
- **技能**：造成伤害或提供效果。支持元素、普攻/重击/战技/大招、生命/攻击/防御/精通乘区，以及 5 种互斥高级属性。新技能在底部编辑，完成后按角色归组；同角色内可调整顺序。
- **圣遗物**：与角色页一致的四卡片切换布局，每次显示一套。固定 4 套，装备角色、套装名字、花/毛/沙/杯/头五个主词条、多条副词条、多条套装效果。
- **统一效果编辑器**：自己、全队、任意角色组合、按角色元素多选或前台角色；生命、攻击、精通、暴击率、暴击伤害变化、敌方抗性、基础增伤、改变倍率及独立乘区；支持正负数、百分比、角色基础/局外/实时数值变量、系数或多条条件公式；有限持续时间或无限长。
- **环境/元素共鸣**：原全局效果栏；没有触发者、不能以自身为对象，可独立选择变量来源角色。效果仍需选全局或实时分类。旧自身目标迁为原角色的自选目标，保留含义。
- **天赋**：采用技能页布局，按角色分组、折叠展开、组内排序；新天赋在底部完成后归组，每条效果可勾选全局。
- **效果列表**：“全局效果 / 实时效果”两栏切换，每次只显示一类；类内按武器、圣遗物、天赋、技能、环境/元素共鸣、独立效果排序，再按角色排序。与原位置编辑同一份定义。
- **敌方属性**：怪物等级非负、默认100，八种抗性分别录入、默认均为10%，支持负抗性。
- **时间轴**：统一“触发效果”入口，先选择来源类别，再选择详细效果。事件只保存引用、起始时间及本次时间/层数设置，不复制或修改效果数值。保留技能、初始前台、切换角色、事件复制与删除。
- **结果**：顶部按角色顺序拼接每位角色的「等级命座标识 + 武器简写 + 角色简写」，各角色间以空格分隔，合计角色及武器金数和限定金数。突出显示 DPS，其次是总伤害、秒数；伤害列表仅列出伤害技能，展开显示四人的基础/局外/实时属性、装备词条，以及此时生效的效果来源、变量x与求值结果。
- **存储**：浏览器自动保存、完整方案 JSON 导入导出、格式和引用校验；自动补全旧方案缺失的新字段。
- **重置方案**：顶部入口需二次确认，可取消、保存当前方案并重置，或使用红色的直接重置。预设库保留；保存并重置先导出JSON并保留一份浏览器备份，可在重置弹窗再次导出该备份。

## 快速导入装备

点击顶部“快速导入”，选择以下来源：

- **GGScanner JSON**：选择 [GGScanner](https://github.com/Anyrainel/GGScanner) 抓包导出的 GOOD v3（也兼容v1/v2基础字段）。从文件角色或已装备物品的 `location` 选择来源角色，再选择计算器中四个角色槽位之一。未装备的背包物品不计入角色。
- **Enka UID**：输入UID，读取 [Enka.Network](https://api.enka.network/#/api) 公开角色展柜，再使用同样的选择与预览流程。账号需在游戏里放入展柜角色并开启“显示角色详情”；API无法通过UID读取未公开的所有角色。

导入窗口分为角色信息、武器与圣遗物三组。角色名称、等级、命座、武器名称、武器主词条（基础攻击力）、武器副词条、圣遗物主副词条可分别勾选；默认勾选全部可用内容，包括套装名字。缺失字段对应选项禁用。确认才替换勾选字段，取消不改方案。角色等级同时更新0/1/3命星，但不猜测基础三维或突破属性。装备效果和时间轴保留；名称按既有规则同步自动效果名。UID点击读取后保存在本地，重新打开或刷新会恢复，不自动发起请求。

GOOD未直接提供武器属性，按武器名称、等级成长曲线与突破阶段还原基础攻击，副词条按单独成长曲线还原；Enka直接读取武器 `FIGHT_PROP_BASE_ATTACK`及副词条，不会误用角色总攻击力。当前捆绑256把武器的查表数据，未知武器会明确提示，可导入其它可用内容。圣遗物副词条按已装备部件的实际值合计，不重复累加rolls或未激活词条。

每个圣遗物部位都有“20级5星圣遗物”，默认勾选并使用先前指定的固定值（例如精通187）。取消勾选后可填写任意有限数值，花与羽毛仅类型固定，数值也可自定义。导入等级20且稀有度5星时勾选，其它等级/空部位不勾选，使用来源数值/0；不再显示“导入：”前缀。类型严格沿用原列表：如导入充能沙漏或治疗头，会在预览明确提示并映射为NOT IMPORTANT。新数值参与局外/实时面板，保存后恢复。

Enka官方接口没有浏览器跨域许可，本地工作台通过 `/api/enka/{uid}` 转发到固定的官方UID端点；使用自定义User-Agent，按ttl缓存并合并并发请求，429后退避60秒，网络请求20秒超时。`npm run dev`、启动脚本及 `npm run preview` 均启用此端点；GitHub Pages版默认通过AllOrigins公共转发；Cloudflare一体化部署包含网页和同域接口，无需单独配置API地址。JSON导入完全本地可用。

数据格式与查表来源见 [快速导入数据说明](docs/快速导入数据说明.md)。

## 当前约定

1. 词条数使用用户指定平均值：3.3% 暴击率、6.6% 暴伤、5% 攻击/生命、6.2% 防御、5.5% 充能、20 精通、17 固定攻击、254 固定生命、20 固定防御。支持小数，例如 1.9 条精通 = 38。
2. 切换装备角色会交换两位角色的对应装备，保持每人一把武器、一套圣遗物。
3. 效果原位置和效果列表共同编辑数值、类型、上限、初始层数及时间预设。时间轴填写本次层数；勾选“使用预设”时持续时间和定时参数跟随原定义，取消后独立保存。
4. 技能为「提供效果」时，将其加入时间轴后，所属效果按技能起始时间生效。伤害技能不产生效果事件。
5. 实时效果生效区间为 `[起始时间, 结束时间)`，同秒按添加顺序处理。全局效果不参与时间轴状态，在每次伤害计算时始终存在；实时变量按该事件当时面板求值。时间轴0.00s标灰展示全局效果，支持折叠，不影响时长。
6. 总时长取时间轴最后一个手动事件的**起始时间**，包括不造成伤害的技能和效果事件；持续时间、自动定时变化不延长统计时长。
7. 全部队伍命名使用每位角色的「等级命座标识 + 武器简写 + 角色简写」，组内无空格，组间一个空格，例如 `95级00精5狼末偶 01芙 01菈 01希`。金数与限定金数独立录入，不自动推导。
8. **DPS、总伤害和单次伤害默认采用暴击期望值**，可切换为暴击、不暴击。切换同步更新整页事件列表、角色总伤害、圆环占比和DPS，不重新计算时间轴；展开详情仍保留全部三种结果和原公式。任何伤害事件出现参数或公式错误时，完整总伤害/DPS显示未完成，并保留已计算部分。总时长为0时总伤害可显示，DPS不可计算。
9. 已完成编辑的方案自动保存在当前浏览器/端口下，技能草稿与未保存弹窗不包含在方案中。建议导出 JSON 备份；切换浏览器或清除浏览器数据不会保留本地方案。

## 新增编辑规则

- 角色元素只有火/冰/雷/草/岩/风/水。物理仍属于伤害类型；角色的物理伤害加成独立填写。旧方案若把角色元素选成物理，会保留原加成为物理伤害加成，并提示重新选择角色元素。
- 效果目标选「按角色属性」时可勾选多个元素，动态匹配该元素的角色；选「前台角色」则跟随事件时点的场上角色。敌方抗性的角色目标控件禁用，详情显示对象为敌方。
- 时间轴 0.00s 的全局效果下方设置初始场上角色，默认为第一个角色。切换事件可改时间、修改角色、复制、删除；同秒按添加顺序生效。技能不会隐式切换角色。伤害详情显示该时点的前台角色和实际效果对象，切换事件不计为伤害事件。
- 圣遗物花固定 4780 生命值、毛固定 311 攻击力，均禁用编辑。沙、杯、头按照对应的固定数值选项配置；杯分别提供七种元素伤害加成46.6%与物理伤害加成58.3%。
- 武器与圣遗物可选副词条，以及沙/杯/头主词条均支持 `NOT IMPORTANT`，始终在列表末尾。该词条不参与伤害计算。花、毛不能选此项。保存键 `notImportant` 不变，兼容原拼写。
- 武器的元素/物理伤害副词条只支持实际百分比输入，因为尚未指定词条数均值。旧方案缺失的沙/杯/头默认 `NOT IMPORTANT`，避免猜测原主词条配置。
- 新增的主词条属于静态装备数据，参与角色局外数值。效果编辑器中明确勾选“局外生效”的全局属性效果也进入该面板。

## 变量数值和高级公式

- **角色基础数值**：基础三维与武器基础攻击力，暴击率固定5%、暴伤固定50%；不含突破百分比或附加属性、武器副词条、圣遗物与效果。突破加成从局外面板开始计入；百分比三维按原基础数值加算，避免把攻击突破反复放大为其它百分比加成的基数。
- **角色局外数值**：基础数值加武器副词条、圣遗物主副词条，以及勾选“局外生效”的全局属性效果。此选项适用于所有来源的全局效果，默认关闭，旧方案缺失时也按关闭处理。实时效果不进入局外面板。
- 局外效果使用基础变量时仍读取原基础数值；使用局外或实时变量时，在局外环境解析，只依赖装备及已勾选的全局效果，不读取时间轴增益。局外前台目标使用初始场上角色。循环引用会报告错误，不无限递归。
- **角色实时数值**：从角色与装备词条出发，加入该事件有效的全部属性效果，动态解析来源角色与前台目标。“局外生效”效果只计入一次；其实时变量仍按命中时的实时数值求值。基础面板不受该选项影响。伤害专用增伤与倍率保留在伤害效果区，不重复折入面板。
- 旧角色的额外暴击率（原值−5）、暴伤（原值−50）、精通、元素/物理加成迁移为突破属性。若旧记录同时有多项，第一项进入突破选择器，其余在“旧方案其它自身数值”折叠区保留并可编辑/删除，不静默丢失；局外/实时面板只计入一次。新角色只配置一项突破属性。请勿重复填写装备贡献。
- 生命、攻击、防御、精通的**变量效果**（基础/局外/实时来源，包括高级公式）直接加算求出的数值，例如结果20表示增加20点，绝不再次按20%乘基础属性；这四类变量的单位固定为数值。手动输入的固定百分比加成仍按原基数计算。暴击率/暴伤效果以百分点直接加算。伤害专用增伤与倍率效果按本次伤害元素、动作、依赖属性和高级标签筛选后进入伤害公式，不自动加到角色所有属性。
- 普通变量输出 `x × 系数`；勾选高级公式后改为按规则输出，不再额外乘系数。
- 多条公式从上往下采用第一条匹配的条件；空条件是兜底，必须放最后。没有匹配则报告错误，不能默认0。
- 例如：第一条 `x > 2000`，公式 `(x - 2000) * 0.04`；最后一条条件留空，公式 `0`。x=2500时输出20；生命、攻击、防御、精通变量表示增加20点，增伤或擢升等百分比效果表示20%。
- 支持 `+ - * / ^`、括号，`min/max/abs/floor/ceil/round/sqrt`；条件支持 `> >= < <= == != && || !`及中文 `＞ ＜ ≥ ≤`。仅解析算式，不运行JavaScript。
- 旧变量模式自动迁移为“角色实时数值”，保留原系数。公式草稿可随本地方案保存，语法错误、除零、数值溢出和未匹配条件会显示错误。
- 原有全局效果归入环境/元素共鸣，移除触发者；原自身目标保留为原角色的自选目标。其他来源的旧全局标记迁为全局分类。全局引用触发事件会清理，不能改变全局效果。

## 直伤公式与等级

- 角色等级默认90，常用下拉选项为90、95、100；1～89级默认折叠，点击“展开1–89级”后选择，收起或刷新后仍保留已选低等级。等级1～90为0命星，95为1命星，100为3命星，命星不再单独编辑。命座只填写命座值；95/100级命名时自动生成 `95级2` / `100级2`，其他等级只写 `2`。
- 常规直伤（未勾选增幅反应）：`(依赖属性 × 有效倍率 + 基础值加成) × (1 + 元素/物理加成 + 常规增伤 + 易伤 − 减伤) × 抗性系数 × 防御系数 × 暴击区`。
- 抗性低于0为 `1 − 抗性/2`，0～75%为 `1 − 抗性`，75%以上为 `1/(4×抗性+1)`。抗性先应用该事件前生效的对应元素减抗，可为负数。
- 防御系数：`(角色等级+100)/[(角色等级+100)+(敌人等级+100)×(1−减防)×(1−无视防御)]`。当前角色效果减防上限90%，无视防御上限100%，二者分开相乘。
- 星月直伤：`[星月系数 × 依赖属性 × 有效倍率 × (1+基础提升) × (1+6×精通/(精通+2000)+专属增伤) + 额外提升] × 抗性系数 × 暴击区 × 擢升最终乘数`。
- 月感电系数3，月结晶1.6，月绽放/星扩散1。时间轴“星超导层数”取1～13，等于上周期元素力+1：1层为0点/20%/1，2层为1点/29%/1.45，之后每层增加1个百分点/0.05，13层为12点/40%/2，不存在0层。当前不自动模拟4秒周期的附着计数。星扩散/星超导直伤按文档要求使用攻击力乘区。
- 高级标签决定公式，技能中选择的实际伤害元素决定所用抗性。通常月感电为雷、月结晶为岩、月绽放为草；本工作台保留自定义组合，未自动推断或覆盖伤害元素。
- 星月直伤不乘普通元素/物理增伤、常规增伤/易伤/减伤、防御区或增幅系数；普通伤害不使用星月专属效果。不会自动生成雷云、月笼或星辉风旋等反应事件。
- 星超导层数**只作用于当前事件**。星超导直伤默认1层，使用表中系数而不再套普通冰雷增伤；普通冰/雷伤害默认“不应用增益”，选择1～13层后使用对应的普通冰雷增伤，不乘星超导系数。其他事件不继承层数。旧方案0～12层自动加1，保持原有系数和伤害；保存starStackVersion=2避免重复迁移。旧系数能精确映射时自动迁移，表外系数保留并提示重选。
- 技能依赖属性可选择基础、局外或实时数值；暴击、星月精通读取当前事件实时数值。尚不模拟角色特殊的释放快照。
- 新增效果细分：基础值加成、易伤、减伤、降低防御、无视防御、星月基础提升、星月增伤、星月额外提升、擢升。所有效果仍可使用三种数值来源和条件公式。技能页不提供星月加成输入；星月基础提升、专属增伤、额外提升和擢升只从圣遗物、天赋、武器、全局或时间轴效果中汇总，同类分别相加。
- 旧方案技能中的星月加成迁移为仅限对应技能的全局效果，原技能配置不再保留；旧星超导系数迁移到其已有事件（不覆盖明确填写的事件值）。旧擢升固定乘数按 `(乘数−1)×100` 转换为百分数，变量/高级公式同样转换输出。迁移后的效果可在全局板块修改或移除技能限制，反复保存不会重复迁移。
- 倍率增加按百分点加算（200% + 20% = 220%）；倍率提升相乘（200% × 1.2 = 240%）。同类效果先分别加算，再先增加后提升。旧数据未注明语义的倍率效果需在编辑器选择，避免静默猜测。
- 擢升只填写百分数，来自所有生效且匹配的效果，先求和再取 `1 + 总和/100`。例如A天赋10%、B武器5%得到最终系数1.15；不会按1.1×1.05连乘。变量与条件公式同样返回百分数值。
- 暴击期望为 `不暴击伤害 × [1 + clamp(暴击率,0,100%）× 暴伤]`，不随机抽取暴击。内部保留精度，显示最多3位小数。
- 旧角色等级迁移优先采用独立等级，否则解析旧备注如 `95级2`，再依据旧命星推导；迁移后命座保存为 `2`。缺失等级与命星时采用90级。旧面板原始数值保持，不自动补齐未录入的角色或武器数据。

## 公式预设与多层效果

- 武器、圣遗物、技能、天赋和环境/元素共鸣原位置的所有效果默认折叠，包括新添加效果；点击标题展开编辑。效果列表继续使用摘要与编辑弹窗。
- 原“空技能”改为“不造成伤害”：不产生伤害记录，参与DPS统计时长，可以绑定并触发效果。技能事件不会自动切换前台。旧方案的 `kind: empty` 同样采用此规则。

- 效果默认名称为“角色名称＋来源类型＋来源名称”，例如 `奥黛塔天赋华彩（队友）`、`桑多涅武器极霸剑`。自动名称随角色和来源名称同步，手动改名后保留自定义值，可点击“恢复默认名称”。旧空名称自动补齐，已有非空名称保留。环境/元素共鸣没有角色前缀。

- 在高级公式中点击“使用公式预设”，填写变量阈值、每档数值、每档属性变化和最大变化量，再点击“生成并替换公式”。默认按比例换算，勾选“每满一档才生效”则向下取整档数；支持负向变化及不限制上限。效果类型、目标和变量角色沿用当前效果配置。
- 桑多涅的示例：效果选择改变元素精通，变量选择桑多涅实时攻击力，阈值0、每100点变化8点、最多160点，生成 `min((max(x - (0), 0) / 100) * 8, 160)`。实时攻击2000或以上时增加160精通。生成后的公式与预设参数一起保存，也可继续手动编辑公式。
- 实时效果可绑定一个或多个技能，包括不造成伤害的技能。释放时触发，作为该事件的子项展示；绑定效果在该次伤害之前生效。技能自身提供的效果默认绑定所属技能，可以取消。
- 实时效果分五类，见下表。所有多层效果初始层数默认0，在0秒直接生效但不生成事件；初始层从0秒按默认持续时间计时，定时器由时间轴触发启动。

| 类型 | 定义中的时间/层数设置 | 每次触发 |
| --- | --- | --- |
| 固定效果 | 默认持续时间 | 刷新整条效果持续时间 |
| 每层独立计时 | 最大层数、初始层数、默认每层持续时间 | 增减层数，正数添加、负数扣除；最早到期优先扣除或满层刷新 |
| 每层独立计时＋定时增减 | 上述设置及默认间隔、增减层数 | 重置层数及定时器；每批层数独立到期，满层继续刷新最早到期层 |
| 每层共用持续时间 | 最大层数、初始层数、默认持续时间 | 重置层数和整条效果持续时间 |
| 共用持续时间＋定时增减 | 上述设置及默认间隔、增减层数 | 重置层数及定时器，统一到期；自动增加不会续期 |

- 时间轴直接显示当前层数；0层显示“当前无该效果”。共用计时类型另显示剩余持续时间。正数定时变化可从0层增长；负数扣到0层停止。首次定时变化在触发后一个间隔；再次触发替换旧定时器。
- “使用预设”默认勾选，只锁定持续时间和定时参数，**本次层数始终可编辑**。取消勾选时保留当前显示值，允许自定义并标注“（已更改）”。效果数值、类型、上限、初始层数不能在时间轴修改。
- 灰色定时事件显示时间、增减层数、当前层数及原触发时间。同秒先处理到期与已有定时器，再按添加顺序处理手动事件。自动事件仅展示到方案末尾，不产生伤害记录、不延长DPS时长。
- 每个来源的效果有独立层数池，手动触发和技能绑定操作同一个池；同时命中多个绑定条件时只触发一次。普通合计值=当前每层值×层数；独立乘区按层数次方。实时变量仍在每次伤害计算时读取当前面板。
- 全局效果逻辑不变，不参与实时层数与计时，0秒默认折叠标灰展示；勾选局外生效时参与局外面板。实时效果（含初始层数）不进入局外面板。
- 浏览器加载或导入旧方案时，旧固定、不自动变化、独立计时、定时增减分别映射到固定、共用计时、独立计时、共用计时定时增减，初始层数设为0；原事件时间参数保留为显式覆盖。旧方案若让同一效果逐事件切换模式，新定义以首个触发模式与上限为准，请按新分类检查该效果。
- 为避免极端间隔阻塞编辑，单次状态重放最多处理100000个定时变化或1000000次批次访问，超出明确报错；灰色事件最多展示5000条并提示，正常计算仍处理全部有效变化。

## 效果命名、合并与独立乘区

- 效果编辑和摘要中，“增伤区”显示为“基础增伤”，“倍率区”显示为“改变倍率”；保存键保持兼容。编辑下拉项与备注显示“造成的伤害提升 X%”“目标受到的伤害提升/降低 X%”等游戏措辞，数值单位和公式位置仍按对应类型处理。
- “基础值加成”和“星月额外提升”合并为一个效果，填写固定增加值 X。普通直伤在基础增伤之前加算；星月直伤在反应系数、基础提升、精通及专属增伤之后加算，再乘抗性、暴击、擢升和独立乘区。旧星月额外提升导入时迁移为此类型，目标及伤害筛选保留。
- 独立乘区直接填系数，缺省为1。例如1.2和1.3两个效果让最终伤害乘1.56；每个适用的效果各乘一次，普通、蒸发融化、星月直伤都支持。支持变量/高级公式、角色与伤害条件筛选、实时触发和持续时间。变层数效果1.2的3层为1.2³，0层无效果。负系数报错，零系数允许；计算详情列出各项系数与乘积。
- 效果列表“添加独立效果”先打开草稿，确认添加才写入方案，取消或关闭不产生条目。独立效果来源可选“无对象”，此时不能选择“自己”为生效对象；变量来源角色仍独立选择。全局/实时分类、局外生效及保存导入保持支持。
- 层数逻辑采用上文五类实时效果；时间轴不能再切换旧模式1/2。

## 逐事件蒸发与融化

- 时间轴中普通火、水、冰伤害可勾选“是增幅反应伤害”。默认不勾选；水锁定蒸发、冰锁定融化，火可选蒸发或融化。星月高级伤害和其他元素/物理伤害不显示此选项，也不乘增幅系数。
- 选择只作用于当前事件。基础系数为水蒸发2、火融化2、火蒸发1.5、冰融化1.5。箭头左侧为本次攻击元素，右侧为目标已附着元素。
- 按 [Alioth 增幅反应公式](https://alioth.wiki/gi/formulae)（2026-11-08核对）：`V = 基础系数 × [1 + 2.78 × E/(E+1400) + B/100]`。`E`为本次伤害角色在命中时的实时精通；`B`为所有生效、匹配的“增幅反应增伤”百分数之和，缺省0。`B`可来自全局或实时效果，也可配置为变量或分层效果，并筛选蒸发/融化。
- 在原常规伤害公式最终乘 `V`，包含基础值加成，非暴击、暴击、期望和DPS同步改变；不额外生成一条反应伤害。普通增伤区与增幅反应增伤分别计算，不重复套用。伤害详情显示反应方向、实时精通、精通加成、反应增伤合计和最终系数。
- 勾选表示手动指定本次有效伤害触发反应，不判断元素量、附着冷却或护盾命中。网页“无伤害数字的护盾命中不计算增幅”的例外仍不模拟；本工具的伤害事件按有伤害数字命中处理。
- 保存/导入/复制保留逐事件选项；取消勾选会移除反应。将技能改为其他元素、效果技能或星月伤害时清除不再适用的反应，改为水/冰则按元素锁定反应。旧方案没有此字段，结果保持不变。

## 手动计算与性能

- 时间轴0秒全局效果默认折叠，点击标题展开，不影响其生效规则。
- 伤害详情上方展示四位角色的伤害圆环图与列表，按角色顺序统计全时间轴，随暴击/不暴击/期望切换。悬停或键盘聚焦圆环显示角色、占比及伤害；点击圆环或角色行查看局外面板。零伤害角色保留列表，仍可查看面板；总伤害为0或未完整计算时不绘制误导性比例。
- 角色局外面板在点击开始计算时随方案快照由后台解析，包含装备与勾选局外生效的全局效果，不读取时间轴增益。所有角色均可查看全部元素和物理伤害加成；修改方案后查看的是上次计算面板，直到重新计算。

- 进入结果页不计算。点击“开始计算”才创建一个后台 Web Worker，计算中按钮禁用，支持取消。
- 修改任意方案参数会停止尚在运行的任务，已完成结果标记为旧结果。再次点击开始计算才更新；切换板块不自动重复计算。
- 历史结果使用当次方案快照显示，避免旧伤害搭配新面板。刷新浏览器后不自动恢复或执行计算，方案数据正常保留。
- 伤害列表每页40条；只有展开的事件才在后台解析四人面板和完整效果详情，详情在当前计算结果中缓存。默认折叠时不为所有事件生成隐藏面板。
- 重置方案会取消任务并清除计算结果。固定数字公式试算仍可在编辑器中即时检查，不触发队伍伤害计算。

## 2026-11-10：定时范围与批量时间轴

- 所有定时变化可设置“在接下来的X秒”，预设与本次覆盖均支持永久。预计次数为 `floor(X / 间隔)`，永久显示∞，首个定时触发在一个间隔之后，终点计入；层数扣到0、共用持续时间到期或再次触发可提前结束。范围结束仅停止定时器，已有层数仍按每层/共用持续时间到期。旧配置缺失范围视为永久。
- 批量添加技能采用同一计数规则。有限批量生成可独立编辑的技能事件；永久批量保存循环规则，根据当前时间轴结束位置展开只读事件，参与伤害和绑定效果计算。规则本身不释放技能。有限批量和单规则最多10000次。
- 点击“多选”后显示事件复选框、全选和批量移动/复制/删除，退出隐藏并清空选择。只选择可编辑主事件，绑定与自动子事件跟随父事件。前/后移动保持相对时间；移动到第X秒将最早事件对齐X秒。复制同理。早于0秒的操作会被拒绝，删除需确认。
- 技能、效果、切换角色分三种背景；所有技能类型背景一致。自动事件保持所属色系，使用更灰的底色、斜纹和自动标识。技能绑定效果在父事件右下方使用效果卡片，连接线对齐时间框中心；只禁止时间轴起始时间输入框的滚轮改值。
- 快速导入默认全选所有可用字段，圣遗物套装名字可独立导入。GOOD通过setKey、Enka通过setNameTextMapHash识别：4件以上同套显示“XXX（4件套）”，两组2件显示“XXX+XXX（2+2）”；单组2件显示“XXX（2件套）”，其余有套装信息时显示“散件”。缺失套装信息不覆盖现有名称。


## 2026-11-10：效果到期、Enka面板与图标

- 时间轴新增效果到期/清除行，样式与自动效果一致。独立层数逐批显示到期及剩余层数，归零显示效果结束；刷新后只显示实际到期时间。已知有限到期点超过最后操作时放在“后续效果结束时间”区域，不延长DPS统计时长；永久效果没有到期行。
- 每层共用持续时间且定时增减的效果，定时范围X不得超过共用持续时间Y；Y有限时禁用范围永久，输入超限会收窄到Y，缩短Y同步收窄X。预设与时间轴覆盖、计算读取均执行同一限制。
- 快速导入新增角色基础三维、角色属性、头像、武器图标和激活套装图标，仍默认全选所有可读信息。Enka原始数据使用fightPropMap的1/4/7字段，4包含武器基础攻击，导入角色攻击前按武器等级、突破和资料表扣除未取整的武器基础攻击；无法可靠拆分时跳过基础三维，保持原值。基础HP/DEF直接使用原始基础值，避免误用2000/2001/2002最终面板。
- 单角色导入与四角色批量导入可切换；批量逐槽对应来源角色，可跳过槽位，禁止重复匹配，一次确认全部应用。JSON与UID两种来源共用流程，缺失项保留旧值。
- 头像在角色设置中可从Enka资料选择或粘贴HTTP(S)图片链接。角色卡片、装备页、效果列表和时间轴使用头像/图标；加载失败退回简写或默认图标。远程图片由Enka按需加载，元素SVG存放本地。
- 套装名称除哈希匹配外增加setId匹配，兼容Enka实时数据与资料表名称哈希不同的情况。激活4件套使用该套花，2+2分别使用两套花，左上/右下缩小排列并留出“+”。武器优先使用API flat.icon，头像采用SideIconName。

元素SVG来源：[Sacr3d/genshin-icons](https://github.com/Sacr3d/genshin-icons/tree/main/Elements/SVG)。颜色参考原神技能文本元素色，取自 [Paimon.moe角色数据](https://github.com/MadeBaruna/paimon-moe/tree/main/src/data/characterData)，为浅色界面适当加深：火#FF9999、水#80C0FF、冰#99FFFF、雷#FFACFF、风#80FFD7、岩#FFE699、草#99FF88。


## 伤害&效果轴

- 点击开始计算后，在计算结果底部生成伤害与效果轴；数据随本次计算结果保存，参数改变后保持上次快照，不在编辑时额外计算。暴击/非暴击/期望切换同步更新伤害柱。
- 时间箭头上方为细伤害柱，悬停或键盘聚焦显示伤害、时间、角色与技能。点击自动切到该事件所在详情页并展开；重复时间的伤害柱并排显示。
- 下方每条实时效果用较粗的持续条显示。触发、重置、定时变化、到期都形成区间边界；变层数条在每段中央标层数，0层期间留空。点击区间定位其开始处对应的具体变化事件，包括初始层数与自动到期。
- 全局效果最下方合并成全程总览条，点击展开各条。悬停显示定义与来源，点击定位上方效果事件详情。效果详情独立分页，变量的具体取值仍查看相应伤害事件详情。
- 轴域截止本次DPS统计终点，持续到结束之后的效果在图中截断。时间轴中的效果结束简称为“效果·结束”；自动到期或自动扣至0层为“效果·自动·结束”。
