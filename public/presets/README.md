# 官方预设库

欢迎通过 **Pull Request** 上传预设。作者审核内容和计算逻辑后合并，合并的条目会随网站部署加入官方预设库。

| 目录 | 内容 | 导出方式 |
| --- | --- | --- |
| 方案预设 | 整队、角色装备、技能效果、敌方与完整时间轴 | 顶部“导出方案” |
| 角色 | 单个角色参数 | 角色“保存预设 → 导出文件” |
| 武器 | 单把武器参数、副词条及效果 | 武器“保存预设 → 导出文件” |

请只提交自己有权分享的预设，不要包含Token、账号凭据、个人UID或其他不必要的个人资料。图片链接应来自可公开使用的来源。

## 投稿步骤

1. Fork仓库，用最新版工作台导出JSON，放进对应文件夹。建议使用短英文文件名。
2. 在 `index.json` 的 `presets` 数组追加条目：

```json
{
  "id": "my-team-v1",
  "kind": "project",
  "name": "预设名称",
  "description": "队伍、适用条件、循环长度及机制说明",
  "author": "你的GitHub用户名",
  "file": "方案预设/my-team-v1.json"
}
```

角色 `kind` 为 `character`、`file` 为 `角色/<文件名>.json`；武器 `kind` 为 `weapon`、`file` 为 `武器/<文件名>.json`。ID必须唯一，文件内容必须匹配分类。

3. 本地运行 `npm ci`、`npm run check:presets`，确认校验通过。
4. 创建PR，说明来源、角色/装备条件、主要机制、计算结果和需要注意的限制。自动校验通过不代表内容已审核；作者确认后才合并。

不改 `index.json` 的JSON不会显示在官方库，并会被校验检查提醒。浏览器中的本地预设不会自动上传。初始库为空，等待经审核的社区投稿。
